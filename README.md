A one-line resignation letter from a cron job that has fired every minute
since March — tired, unloved, and quietly passive-aggressive about the
2 a.m. run it leaves behind.

`main.ts` (Node 22, no dependencies) writes the single line to
`/output/entry.txt` and self-checks that it stays within the 140-character
limit. Run it with `node main.ts`.
